# EDA
Diwali Sales Analysis -- Exploratory Data Analysis (EDA)
📌 Project Overview
This project performs an Exploratory Data Analysis (EDA) on a Diwali
sales dataset to understand customer purchasing patterns, sales
performance, and product demand.
The analysis uses Python, Pandas, NumPy, Matplotlib, and Seaborn to
clean the dataset, explore customer characteristics, and visualize sales
trends across different dimensions.
The main objective is to identify patterns in: - Customer demographics -
Gender and age groups - State-wise orders and sales - Marital status -
Occupation - Product categories - Product-level order performance
🎯 Objectives
The key objectives of this analysis are:
1. Understand the structure and quality of the sales dataset.
2. Clean unnecessary columns and missing values.
3. Analyze customer demographics.
4. Compare purchasing behavior by gender and age group.
5. Identify states with the highest number of orders and sales.
6. Analyze purchasing patterns based on marital status.
7. Understand sales contribution by occupation.
8. Identify high-performing product categories.
9. Identify products generating the highest number of orders.
10. Present the findings through clear visualizations.
📂 Dataset
The analysis starts with a Diwali sales dataset containing:
- 11,251 rows
- 15 columns
Important columns include:
  Column               Description
  User_ID            Unique customer identifier
  Cust_name          Customer name
  Product_ID         Product identifier
  Gender             Customer gender
  Age Group          Customer age group
  Age                Customer age
  Marital_Status     Marital status indicator
  State              Customer's state
  Zone               Geographic zone
  Occupation         Customer occupation
  Product_Category   Product category
  Orders             Number of orders
  Amount             Purchase amount
🧹 Data Cleaning
The following data-cleaning steps were performed:
1. Removed irrelevant columns
The dataset contained two blank/unrelated columns:
- Status
- unnamed1
These columns were removed from the DataFrame.
2. Checked missing values
Missing-value analysis showed that the Amount column contained 12
missing values.
3. Removed missing records
Rows containing missing values were removed using:
df.dropna(inplace=True)
After cleaning, the dataset contained 11,239 records.
4. Changed data type
The Amount column was converted from float to integer:
df['Amount'] = df['Amount'].astype('int')
🔍 Exploratory Data Analysis
1. Gender Analysis
The project analyzes:
- Number of customers/orders by gender
- Total sales amount by gender
A count plot and sales comparison chart were created to understand
gender-wise purchasing behavior.
2. Age Group Analysis
The analysis explores:
- Distribution of customers across age groups
- Gender distribution within each age group
- Total sales generated by each age group
This helps understand which customer age segments contribute most to the
sales.
3. State-wise Analysis
Two state-level analyses were performed:
Top 10 states by number of orders
States were grouped by Orders and sorted in descending order to
identify the top 10 states based on order volume.
Top 10 states by sales amount
States were also grouped by Amount to identify the states contributing
the highest sales revenue.
4. Marital Status Analysis
The project examines purchasing behavior based on marital status.
The analysis includes:
- Customer/order distribution by marital status
- Sales amount by marital status and gender
This provides a comparison of purchasing patterns between different
marital-status groups.
5. Occupation Analysis
Occupation-based analysis was performed to understand customer
purchasing behavior across professions.
The project analyzes:
- Number of customers/orders by occupation
- Total sales amount generated by each occupation
This helps identify occupations associated with higher purchasing
activity.
6. Product Category Analysis
The analysis investigates product-category performance using:
- Number of orders by product category
- Total sales amount by product category
The top product categories based on sales amount were also identified.
7. Product-Level Analysis
Product-level analysis was performed using Product_ID.
The project identifies:
- Top 10 products based on total number of orders
- Product-level order performance using grouped order data
This helps identify products with comparatively high demand.
